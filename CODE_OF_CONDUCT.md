# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, and focus on what is best for the
project and its users. Harassment and personal attacks are not accepted.

Report unacceptable behaviour by opening a
[private security advisory](https://github.com/harsh01103/TextInsight/security/advisories/new)
or by contacting the maintainer through their GitHub profile. Reports are handled privately.
